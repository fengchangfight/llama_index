# AGENTS.md

This file contains the conventions and rules for code reading sessions in this repository.

## Code Reading Session Rules

1. **Knowledge Recording**: During multi-turn discussions, important knowledge points and insights from our conversations must be recorded in `docs/codereading.md`.

2. **Methodology Recording**: Code analysis approaches, debugging techniques, and analytical methods discovered or demonstrated during our sessions must be documented in `docs/mechanism.md`.

3. **File Locations**:
   - `docs/codereading.md` — accumulated knowledge points from code reading discussions
   - `docs/mechanism.md` — methodologies and analytical frameworks for code analysis

4. **Update Discipline**: Both files should be updated proactively after meaningful discussions, capturing key takeaways without requiring explicit prompts from the user.
